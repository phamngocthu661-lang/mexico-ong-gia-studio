# SEO Homeless Story v2.0

## Input tối thiểu

1. Full script
2. Final title đã chốt

## Skill sẽ tự làm

- đọc toàn bộ script
- khóa dữ kiện
- kiểm tra title khớp script
- tự chọn content/SEO family
- tạo tóm tắt viral
- description
- 5-8 hashtags
- tags <=500 ký tự
- thumbnail strategy + prompt
- optional arrow note
- chọn cảnh hook thật từ script
- tự quyết trailer 10/20/30s
- tạo 1-3 Omni prompt, mỗi prompt đúng 10s và có nhiều shot ngắn

## Không làm mặc định

- không viết lại title
- không tạo 4 title để chọn
- không bịa scene/tuổi/giá/phòng/vật thể
- không dùng talking-head/lip-sync cho trailer
