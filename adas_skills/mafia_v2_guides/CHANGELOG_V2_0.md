## Explicit limitations
Tests use synthetic long text for mechanics, not literary merit. A checksum proves no unauthorized file changes, not whether the story is good. QA double-read input is a reviewer assertion with grounded exact anchors, not proof of human-complete analysis. No images or videos are rendered by this package.
